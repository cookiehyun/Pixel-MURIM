# 남은 일 메모

## 온라인 SYNC ERROR (2026-11-17, 확인 대기)
- 윈도우 ↔ 윈도우, 같은 버전(버전 검사 통과)인데 대전 시작 직후 "SYNC ERROR … FROM FRAME 0".
- 진단 추가함(c71c2a9): 오류 화면에 ME / PEER 상태 줄(캐릭터·체력·위치·상태·경기 시계)이 나온다.
- 다음에 할 일: 사용자가 두 사람 화면 사진 + 연결 방식(QUICK MATCH / ROOM CODE / DIRECT IP, 누가 방장)을 보내 주면 두 줄을 비교해 원인을 고친다.
