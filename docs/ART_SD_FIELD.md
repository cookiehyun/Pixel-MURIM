# 스토리 필드용 SD 그림 주문서 (ChatGPT용)

필드(걷는 맵)에서만 SD 인물을 쓴다. 대전은 지금 그림 그대로.
기준 그림: `docs/art/sd/danwoo_ref.webp` (사용자가 만든 SD 단우), 배경 화풍: `docs/art/sd/village_ref.webp`.

## 받는 법

1. **매번 기준 그림을 첨부**합니다. 단우가 아닌 인물을 그릴 때도 같은 크기·화풍을 맞추려고 첨부합니다.
2. 한 장에 4프레임, 가로로 나란히. **배경은 단색 #FF00FF(자홍색)** 으로 받습니다(제가 지웁니다).
3. **01번(단우 대기)을 먼저** 뽑아 보내 주세요. 크기와 픽셀이 맞는지 확인한 뒤 나머지를 뽑습니다.
4. PNG로 저장해 주세요.

## 공통 문장 (매번 맨 앞에)

```
Pixel art sprite sheet in exactly the same style, pixel size and proportions as the attached chibi character (big head, short body, thick dark outline, flat colors with 2-3 tones).
Draw 4 animation frames side by side in one wide image, all the same size, standing on the same ground line, evenly spaced, not overlapping.
Strict side view facing right, full body. Same head size and same clothes in every frame; only the pose changes.
Plain flat background color #FF00FF. No text, no numbers, no shadow on the ground.
```
단우가 아닌 인물이면 공통 문장 뒤에 이 줄을 넣습니다.
```
The attached image is only the style and size reference. Do not draw that character. Draw this character instead:
```
