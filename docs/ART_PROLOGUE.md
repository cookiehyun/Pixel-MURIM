# 서장 「혈월의 밤」 그림 주문서

서장은 컷과 대사로 흘러가는 연출 장면이다. 청풍촌(장면 1)만 직접 달린다(→ 를 누르며 불길 사이를 달림).
모든 장면에 붉은 달빛이 깔린다.

- 인물 기준 그림(지금 게임 화풍, 관절 뼈대로 그림): `docs/art/cast/<이름>.png`, 전체 비교 `docs/art/cast/lineup.png`
- 배경 구도 그림: `docs/art/bg/<번호>.png`, 한눈에 `docs/art/bg/_all.png`
- SD 받는 법과 공통 문장은 `docs/ART_SD_FIELD.md` 와 같다 (SD 단우 기준 그림 첨부, 배경 #FF00FF, 4프레임, PNG).
  새 인물은 **SD 단우 그림 + 그 인물의 기준 그림(cast/*.png)** 두 장을 같이 첨부하고 이렇게 쓴다:
  ```
  Use the first image for the chibi style and size. The second image shows this character's design (colors, hair, clothes): draw that character in the chibi style.
  ```
