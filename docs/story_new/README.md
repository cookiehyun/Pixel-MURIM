# Pixel MURIM — 「혈월」 새 각본

이 폴더는 `docs/story`와 별도로 읽는 새 연속 각본이다. 서장은 백 년 전 혈교의 난을 다루며, 현재의 여섯 습격은 각 인물의 첫 장에서 시작한다. 여섯 개인 편은 같은 사건을 다른 시점에서 따라가고, 천마 편에서 정보가 합쳐져 공동 종장으로 이어진다.

서장 이후 1~6은 자유 순서다. 여섯 편의 엔딩을 보면 천마 편, 천마 편 이후 종장이 열린다. 처음 읽을 때는 표 순서를 권한다. 인물은 플레이어가 다른 편에서 본 사실을 자동으로 알지 못한다.

## 확정된 결말

1. 백무진은 무림맹주이자 **혈교 부교주**다. 혈마와 별개의 인물이며 혈마로 변신하지 않는다.
2. 무영의 마지막 한 획은 **종장 4장의 야차와의 일대일 결전**에서 완성된다. 진을 부수는 만능 기술이나 혈마를 쓰러뜨리는 결정타로 쓰지 않는다.
3. 일행은 백무진과의 전투에 승리한다. 그러나 백무진이 중앙 제단으로 가는 길을 끝까지 막아 **부활을 중단시킬 시간을 소진시킨다**.
4. 혈마는 자신의 육신으로 **실제로 부활한다**. 환영·빙의·불완전한 가짜 부활로 처리하지 않는다. 전투에서 자력으로 움직이고 자기 무공을 쓴다.
5. 마지막 보스전의 조작 캐릭터는 **단우 + 천마 고정 태그**다. 두 사람이 혈마를 직접 쓰러뜨린다.
6. 나머지 인물들의 구출과 진 차단은 사람들을 살리고 혈마의 추가 흡수·외부 재생을 끊는 성과다. 이미 끝난 부활을 취소하거나 혈마를 대신 처치하지 않는다.

## 각본 표기와 전투 원칙

각 장에는 날짜·장소·목표·전투·장면과 대사·전투 결과·다음 장으로 가는 이유를 적었다. 컷 설명은 제작 지시이고, 이름 뒤의 대사가 화면에 표시할 본문이다. 긴 대사는 문장 단위로 화면을 나눈다.

- `[컷]`: 정지 그림 또는 짧은 화면 전환. 대규모 군중은 배경과 대표 인물로 표현한다.
- `▶ 전투`: 실제 조작 구간. 적 이름과 승리 목표를 명시한다.
- `▶ 승리 후 / 패배 시`: 이야기 결과와 재도전 대사. 승리와 목표 달성을 구분하되, 결과를 미리 연출한다.
- `⇄`: 같은 사건의 다른 시점. 공통 대사는 동일하게 사용한다.
- 한 장의 전투 수를 맞추려고 우호 인물끼리 이유 없이 싸우지 않는다. 보호 대상, 추격 대상, 통행 목적이 충돌할 때만 대전으로 이어진다.
- 개인 편 마지막 적을 꺾었다고 그 적을 반드시 죽인 것으로 처리하지 않는다. 야차는 개인 편에서 정체가 드러나고 종장에서 최종 패배한다.
- 원래 폴더의 연표·용어를 섞지 않는다. 이 버전에서 현대 습격일은 평범한 달빛의 **참변 0일**이고, 붉은 달은 종장에서 혈천진이 일으킨 현상이다.
