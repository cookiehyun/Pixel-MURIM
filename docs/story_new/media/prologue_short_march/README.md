# 서장 두 번째 기상·진군과 우물 손

[이전 재생](before.mp4) · [수정 후 재생](after.mp4) · [같은 우물 프레임 비교](well-comparison.png)

576×300 게임 화면을 초당 20프레임으로 녹화했다. 두 영상 모두 두 번째 기상에서 시작하고, 아홉 명이 멈추는 순간 해설을 넘겨 지도 암전까지 보여준다.

| 구간 | 이전 | 수정 후 | 브라우저 재생 실측 |
|---|---|---|---|
| 두 번째 기상 | 133틱 | 80틱 | 6.63초 → 3.98초 |
| 진군 | 112틱 | 50틱 | 5.60초 → 2.50초 |

세 몸의 소환 시작 간격은 12틱에서 6틱으로 줄였다. 기존 기상 자세를 차례대로 거쳐 마지막 무인이 62틱에 선다. 소환 기운이 걷힌 뒤 10틱간 대열을 보여준다. 아홉 명은 같은 가감속으로 약 7월드픽셀 전진한다. 해설은 진군 6틱에 열리고, 해설 완료 입력을 받으면 바로 암전이 시작된다.

우물 손은 [well_hand.png](../../../../web/data/hi/sd/gangsi/well_hand.png)를 사용한다. 네 손가락의 관절과 가늘어지는 손톱을 회백색과 짙은 보라색으로 구분했다. 기존 수면선에서 22픽셀까지 드러나고 마지막 자세를 30틱 유지한다.

> 첫 그림의 혈강시가 두 번째 그림의 우물에서 손을 들어 올리는 게임용 픽셀아트 스프라이트 한 장. 투명 배경에 손등 윗부분과 길이가 다른 사람 손가락 네 개만 그려 줘. 가장 긴 중지부터 약지·검지·새끼손가락의 높이를 어긋나게 하고 관절은 마르고 각지게, 손끝은 가늘게, 손톱은 짧고 길쭉하게. 회백색 피부, 중간 회색, 어두운 보라색 윤곽과 손톱 밑 그림자로 명암을 나눠 줘. 30×22픽셀에서 읽히는 형태로, 아래는 수면선에서 수평으로 자른다. 초록색, 둥근 흡반, 엄지·팔·얼굴, 물결과 배경은 제외.
