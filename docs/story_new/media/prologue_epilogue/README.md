# 서장 후반부 재생 자료

[전체 영상 · 58.45초](epilogue.mp4)는 Chromium에서 576×300, 초당 20프레임으로 녹화했다. 결전이 끝난 직후부터 마지막 붉은 달까지 이어지며 A로 해설을 읽는 시간도 포함한다.

| 영상 위치 | 화면 |
|---|---|
| 약 9초 | 검붉은 피가 손가락에 닿고, 손등에서 손목으로 핏줄이 번쩍인다. |
| 약 18~31초 | 우물을 같은 위치에 둔 채 폐허가 집터와 장터로 바뀌고, 주민들이 들보를 나른다. |
| 약 51초 | 두 번째 우물 파동 안에서 창백한 손끝이 수면을 스치고 바로 암전한다. |
| 약 56초 | 붉은 달 아래 ‘서장’과 ‘「혈월의 밤」 끝’이 뜬다. |

세 시대에는 기존 그림을 사용했다. 우물의 손끝은 수면 아래를 가린 픽셀 연출이다. 별도 원화로 그릴 때 사용할 프롬프트와 기준 PNG를 아래에 둔다.

**우물 손끝 원화용 프롬프트**

> 첫 번째 이미지의 우물과 두레박, 달의 반사, 물결, 카메라를 그대로 유지한다. 표시된 손끝 위치에 두 번째 이미지의 혈강시 피부를 참고해 달빛을 받은 회녹색 검지와 중지 끝만 그린다. 576×300 픽셀아트, 두 손끝을 합쳐 약 19×12픽셀. 수면 바로 위에 짧은 손톱과 마지막 마디만 보이고 손바닥·팔·얼굴은 모두 물속에 잠겨 있다.

첨부할 파일은 [well-fingertips.png](well-fingertips.png)와 [01_gangsi_model.png](../../../art/prologue_gangsi/01_gangsi_model.png)다.
