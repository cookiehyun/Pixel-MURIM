### 진군

- 9e92d46에서는 인물별 보폭과 이동 거리가 달랐다. fa803f8에서 출발 가속과 걷기 기준점 보정이 들어갔지만, 여전히 13~34월드픽셀의 서로 다른 목적지에 도달하면서 중간부터 간격이 변했다. 브라우저가 밀린 틱을 한 화면에 처리할 때 이동량도 커졌다. 동일한 225ms 지연을 준 재생에서 앞쪽 혈강시의 화면 이동은 수정 전 4px, 수정 후 1px였다.
- 원본 걷기 세 프레임의 발 기준 높이는 모두 35다. 머리(3~9행)와 다리(25~34행)의 불투명 픽셀 중심은 첫 프레임을 기준으로 약 1원본픽셀 옮겨간다. 몸통(13~22행)은 둘째 프레임에서 약 1.4픽셀, 셋째에서는 약 0.1픽셀 달라진다. 기존 머리 기준 보정을 유지하고 대열 전체의 수평 이동을 먼저 화면 픽셀에 맞췄다.
- 마지막 소환이 끝나고 약 반 초 뒤, 아홉 명이 출발한다. 최고 속도는 0.18월드픽셀/틱, 총거리는 18월드픽셀이다. 24틱에 해설이 뜨고 112틱에 대열이 함께 멈춘다.
- CSV는 실제 화면과 아틀라스를 대조한 관측값이다. 월드 x는 프레임 자체의 기준점 차이를 보정한 화면 중심을 3으로 나눈 값이다. 빠른 입력 1,116건, 긴 대기 2,097건에서 같은 틱의 좌표와 프레임이 일치했다. 기상에서 진군으로 바뀌는 순간의 이동은 0px, 진군 중 틱당 이동은 0~1화면픽셀이었다. 두 입력 경로에서 암전이 시작된 시점은 각각 112틱과 222틱이었다.

### 결전과 손

- 대치 해설을 넘긴 뒤 267틱에 혈마가 쓰러지고, 294틱(14.7초)에 사망 해설이 열린다. 1·55·113·210틱에서 각각 SKIP하여 정상 종료와 비교했다. 혈마는 바닥에 쓰러지고 맹주는 검을 내리며 천마는 오른쪽을 향해 발검 상태의 앉아 방어 자세를 취한다. 정상 종료와 SKIP PNG는 픽셀 단위로 동일하다.
- 손 그림에서 피는 바닥 홈을 따라 검지 끝으로 역류하고 흉터로 스며든다. 이펙트가 사라진 뒤 150틱 더 해설을 열어 둔 상태에서도 손과 바닥은 처음의 정지 화면과 일치했다.
- TypeScript와 Vite 빌드, Playwright 서장 완주·전장·지도·제단·진군 검사를 통과했다. 서장이 완료되고 개인 편 6개가 열렸다.
