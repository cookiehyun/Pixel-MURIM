## 전장과 제단

- 9e92d46에서 혈강시들의 협공 종료 위치가 바뀌었다. 두 번째 기상과 진군은 같은 시작 좌표를 썼지만, 진군 첫 틱부터 대열 번호가 보행 프레임에 더해졌다. 여섯 중 세 명이 제자리에서 곧바로 다른 걸음 자세로 바뀌었다. 세 프레임의 발 앵커는 각각 (12,35), (10,35), (10,35)이며 머리 중심은 첫 자세보다 약 한 그림 픽셀 앞으로 치우쳤다. 이전에는 이동도 세 화면 픽셀 단위로 반올림했다.
- 기상 효과가 걷힌 뒤 반 초간 선 자세를 유지한다. 진군은 같은 자세와 바닥선에서 출발하고, 실제 이동 거리로 걸음 주기를 정한다. 출발 가속과 얼굴 중심 보정은 진군에만 적용했다. [수정 전 GIF](march-before.gif) · [수정 후 GIF](march-after.gif)
- 이전 제단 타이머는 497틱에 혈마가 쓰러지고 529틱에 해설이 나왔다. 새 결전은 진격 해설을 넘긴 뒤 378틱(18.9초)에 혈마가 쓰러지고 408틱(20.4초)에 해설이 나온다. 반복 공방과 삼절검 낙하를 덜고, 천마가 검으로 남긴 상처 때문에 혈마의 다음 공격이 끊기게 했다.
- 두 수장을 왼쪽으로 보내던 이동 명령은 200a794 이전 각본에 있었다. 작업 시작 버전에서는 퇴장이 재현되지 않았다. 현재 천마는 검을 든 채 쓰러져 있고, 맹주는 혈마가 쓰러진 뒤 검을 내린다. 천마의 발검 세트에는 지친 몸을 일으키는 연속 자세가 없어, 쓰러진 구도를 택했다.

## 검증 결과

TypeScript·Vite 빌드, Playwright의 전장·지도·제단·서장 전체 진행 테스트를 통과했다. 전장에선 9명의 출발·보행·정지 자세를 실제 캔버스에서 확인했다. 진군 해설을 즉시 넘길 때와 기다릴 때, 암전 전 첫 38프레임에서 병력이 있는 화면 영역이 픽셀 단위로 일치했다.

대치 해설을 9초 더 읽어도 전투는 시작되지 않았다. 정상 재생, 전투 시작 직후, 피흡수, 폭주, 백일천검에서 각각 확인했다. 누른 채로 유지한 A는 다음 해설을 넘기지 않았고 정상·SKIP의 세 인물과 바닥 및 배경이 일치했다. 다섯 경로 모두 서장 완료 저장값이 같았다. 개인 편 6개의 해금, 단우의 A 약공격, 필드의 촌장 조사도 확인했다. 서장 전체 진행 중 브라우저 오류는 0건이었다.
