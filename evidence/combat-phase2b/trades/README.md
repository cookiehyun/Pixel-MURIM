# 12px 단우 미러전 동시타

1F에 양측 약손을 누르거나, 1F에 한쪽 강발과 7F에 상대 약손을 누른다. 동시타 직후 양쪽 모두 위 방향을 유지해 첫 점프 프레임을 측정했다. 조작 슬롯과 좌우 방향을 독립적으로 바꾼 12회 결과가 before.json과 after.json에 있다. 각 로그에서 1P의 인덱스는 0, 2P는 1이다. displayed는 접촉 직후 트레이닝 HUD가 읽는 ADV이며 actual은 상대 점프 프레임에서 조작 캐릭터 점프 프레임을 뺀 값이다.

| 입력 | 접촉 | 공용 히트스톱 (전 → 후) | 수정 후 점프 | 수정 후 ADV |
|---|---:|---|---|---|
| 약손 ↔ 약손 | 7F | 9F → 9F | 양쪽 35F | 양쪽 0F |
| 1P 강발 ↔ 2P 약손 | 13F | 9F → 12F | 1P 44F, 2P 59F | 1P +15F, 2P −15F |
| 1P 약손 ↔ 2P 강발 | 13F | 12F → 12F | 1P 59F, 2P 44F | 1P −15F, 2P +15F |

Playwright와 Chromium을 준비한 뒤 검사할 버전의 web 디렉터리에서 Vite 개발 서버를 실행한다. 저장소 루트에서 아래 명령을 사용한다. 테스트 페이지에서만 훈련 더미에 보조 키보드를 연결한다. 공격과 점프에는 DOM 키 이벤트와 실제 게임 입력·대전 루프를 사용한다.

```sh
GAME_URL=http://127.0.0.1:4190 node evidence/combat-phase2b/trades/verify.cjs after
```

기준 로그를 재생성할 때는 1fde05b 서버를 지정하고 before를 전달한다. CHROME_PATH의 기본값은 /usr/bin/chromium이다.

기존 2B의 일반 행동 28건, 연계·반격·헛침 각 6건, 발동 1F 변경 검사를 통과했다. 양방향 동시 KO, 스토리 서장 완료와 개인편 6개 해금, 온라인 락스텝 양측 130프레임 재생(최종 해시 610093141), TypeScript·Vite 빌드도 통과했다.
