# 메인 스레드가 밀린 동안의 대전 입력

Chromium에서 약 63ms 동안 메인 스레드를 점유하고, 외부 CDP 세션에서 8–11ms와 25–28ms에 키 또는 터치를 발생시켰다. 게임의 RAF 콜백은 네 이벤트가 전달된 뒤 호출한다. 브라우저의 시계와 DOM 이벤트 시각은 그대로 사용한다. 로그의 `sourceMs`와 `deliveredMs`는 같은 시작점에서 잰 발생·전달 시각이다. `inputs`는 단우가 받은 프레임별 버튼 비트(약손 1, 강손 2)이고, `hits`는 상대 체력의 실제 감소다.

| 입력 | 7ec061b에서 인식 | 수정 후 인식 | 수정 후 명중 |
|---|---|---|---|
| 키 A→S | 4F 마스크 3 | 1F A, 2F S | 7F 30, 26F 90 |
| 키 A→A | 4F A | 1F A, 2F A | 7F 30 |
| 터치 A→A | 5F A | 1F A, 2F A | 7F 30 |
| 1F·2F를 이미 처리한 뒤 도착한 8ms의 A | 4F A | 다음 미처리 프레임인 3F에 한 번 | 9F 30 |

터치의 수정 전 관측 프레임은 브라우저의 포인터 전달 시각에 따라 달라진다. 이 실행에서는 78–80ms에 전달됐다. 각 시도는 단우 미러전, 중심 거리 15px에서 90개 대전 프레임 동안 관측했다.

## 재실행

Playwright와 Chromium이 있는 환경에서 검사할 버전의 `web` 디렉터리에서 Vite를 실행한다. 기본 주소는 `http://127.0.0.1:4190`이다. 이 디렉터리의 스크립트는 저장소 루트에서 다음과 같이 실행한다.

```sh
node evidence/combat-phase2a/delayed-input/replay.cjs after
```

기준 버전을 재현할 때는 `7ec061b`의 Vite 서버를 `GAME_URL`로 지정하고 같은 스크립트에 `before`를 전달한다. Chromium 경로는 `CHROME_PATH`로 지정한다. 각 실행은 해당 버전의 JSON을 갱신한다. 기존 2A 전체 비교는 상위 디렉터리의 `verify.cjs after`로 실행한다.
