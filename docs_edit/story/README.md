## 플레이 순서와 수첩

1. 서장 「혈월의 밤」 뒤 단우·철산·무영·설화·흑림·홍련 중 누구든 선택한다.
2. 각 편은 일곱 장이다. 1:1 대전, 동료와의 태그 대전, 전투 없는 장면을 이야기의 전환점에 배치한다. 선택한 편의 마지막 대전을 마치고 엔딩 컷을 보면 해당 편의 클리어를 기록한다.
3. 여섯 편 클리어 후 천마 편이 열린다. 천마 편 6장은 단우 편 마지막 대전 직후에서 시작한다. 종장은 천마 편의 엔딩 뒤에 열린다.
4. **수첩에는 플레이어가 본 면만 먼저 표시한다.** 예를 들어 홍련부터 플레이하면 ⑤에 ‘맹주 방의 백단향’만 적힌다. 이후 흑림 편을 보면 ‘가면 의뢰인의 향’이 옆에 붙는다. 흑림부터 시작해도 두 기록이 모인 시점에 같은 문장이 열린다. 단서 기록과 각본 해금은 따로 처리한다.
5. 같은 날의 겹침은 [설정집의 일정표](bible.md)에서 맞춘다. 플레이어가 앞선 편에서 본 사실을 다른 인물이 대사로 쓰려면 그 사람이 직접 보거나 들은 장면이 있어야 한다.

## 각본 표기법

```
### 2장 「객잔의 칼」
장소: 낙양 외곽 객잔 '취선루' · 밤 · 비
대전: 무영 (1:1) · 무대: 객잔
단서: 없음

[컷] 장면 설명. 화면에 보이는 것만 쓴다.

단우: 대사 한 줄은 22자 안팎.
      길면 두 줄까지. 한 화면에 최대 세 줄.
무영: (낮게) 괄호는 말투나 동작 지시.
??? : 이름을 아직 모르는 인물.

▶ 대전 시작
▶ 승리 후
▶ 패배 시 (다시 하기 전에 나오는 한마디)
```

- **[컷]** 정지 그림 한 장 + 짧은 설명. 연출용.
- **대사 길이:** 한글 글꼴(8px)이 들어가면 한 줄 약 22자. 한 화면 세 줄을 넘기지 않는다.
- **장마다:** 대전 앞 대사 3~8화면, 대전 뒤 2~6화면이 기준. 컷신이 긴 장(서장, 회상)은 예외.
- **다른 편과 겹치는 장면:** `⇄ 겹침: 무영 편 2장` 처럼 표시한다. 두 편의 대사는 같은 사건을 다른 쪽에서 본 것이라 서로 어긋나지 않아야 한다.

## 대사와 연출

- **말의 높낮이로 신분과 거리를 드러낸다.** 처음 보는 사람끼리는 하오체("그렇소", "비키시오"), 윗사람이 아랫사람에게는 하게체("왔는가", "가 보게"), 적이나 아랫사람에게는 하라체("비켜라"). 반말은 아주 가까운 사이에서만.
- **강호의 호칭을 쓴다.** 노부, 빈승, 본좌, 본교, 소협, 낭자, 대사, 시주, 노선배, 형장, 귀하, 네놈.
- **감정을 말로 설명하지 않는다.** "나 화났어" 대신 손이 멈추거나 말이 끊긴다. 컷 설명과 괄호 지시로 보여 준다.
- **명대사를 만들려고 하지 않는다.** 한 장에 무게 있는 말은 많아야 한 줄. 나머지는 담백한 주고받음.
- **농담은 마르게.** 귀여운 말, 현대 유행어, "~지?" 같은 확인 질문, 밥 약속 같은 훈훈한 마무리는 쓰지 않는다.
- **무공은 짧게 말한다.** 기술 이름을 외치지 않는다. 상대의 무공을 알아볼 때만 이름을 말한다("아미의 설산비각이로군").
- **한자어는 쉬운 것만.** 사자성어는 한 편에 두세 번 이하.
